# v4.3 更新速览（2026-10）

> 本版核心：**把"修边"从错误前提里救回来，并确立"创意优先、不强制对称"的方法论。**

## 1. 修边纠偏（右半"全花"事故复盘）
- **事故**：4v4 竞技图被反馈"右半边完全没修边"。
- **真因**：为追求"左右像素级对称"，先用了**复制镜像**（右半直接抄左半 tile → 过渡方向全反，整片花掉）；又改用**翻转镜像（交换左右角的 tile）**——但本 tsx **"交换角"≠"像素水平翻转"**（实测 936 个签名瓦片仅 8 个真匹配，0.9%），翻转同样贴错（与真镜像差 74% 像素）。期间加的 `clean_solid_spikes` 还合并出 60 个 `{草,土,高草}` 2×2 花屏。
- **正解**：删除所有镜像 hack 与 `clean_solid_spikes`；渲染层回到**原生 `autotile`**（按地形自然拼接，两半各自都干净）。**Rusted Warfare 瓦片不支持逐格翻转，本图集无法靠贴图做到像素镜像。**
- **修边真标准 = 零花屏，不是对称**：新增 `gen_combined.verify_no_flower()`（水族 7/8/9/23 归一后，任一 2×2 块 >2 种地形类即判花屏），非 0 直接抛错拒出图。

## 2. 理念修正
- **不强制 100% 对称**：地图按 AI 创意生成，让用户看瑕疵再迭代。
- 只有"用户明确要求对称"时，才做**地形布局对称**（且只 mirror 栅格，绝不 mirror 贴图）。

## 3. 诊断工具（`gen_combined.py` 新增）
| 函数 | 作用 |
|---|---|
| `verify_no_flower(cat_grid)` | 真·花屏检测（>2 地形类/2×2，水族归一）；非 0 拒出图 |
| `edge_metrics(cat_grid)` | 权威修边量化：iso / cnt0 / diagonly |
| `edge_pass_rate(cat_grid)` | 修边正确率 %（skill 硬门槛 98%） |

## 4. 湖岸美化（同版补丁）
- `build_lake` 加低频噪声做**有机海岸线**（不再完美圆）；剖面改为 **草→沙滩(米黄)→浅水→深水**；`carve_islands` 给岛加环岛沙滩。
- **桥只覆盖深水、不碰岸边沙/草**（否则桥槽壁凑出 `{草,沙,浅滩}` 三类花屏）。

## 5. 新增示例生成器
- `gen_5v5_riven.py`：《五脊裂原》220×220 5v5 纯陆地——**中路汇流 + 中央共享富矿** 的"配合向"范例（山脉只留两翼、5 线在中央汇合、富矿全压共享竞技场）。

## 6. 保留的硬约束
- 容器三层 Ground/Items/Units 名字精确、顺序正确、尺寸/格数一致。
- 触发器仅 `map_info`(skirmish) + `camera_start`；引用闭合。
- 装饰只放透明底白名单道具（890/891 树、718/719/754 岩石、711/712/714/898 草簇；**高石上不撒装饰**）。
- 官方三件套：`scripts/check_container.py` / `verify_tmx.py` / `check_decor_tiles.py` 全 PASS 才交付。
