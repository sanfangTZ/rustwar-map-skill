# 装饰瓦片白名单 / 黑名单（V4.1 实测定案）

> 结论来源：对 `地面层整合.png`（36 列 × 20px 格，tsx 声明 tilecount=1080）逐格
> alpha 扫描 + 8 倍放大肉眼核对，两轮独立验证。体检脚本：
> `python3 scripts/check_decor_tiles.py 'X.tmx'`（退出码 0=通过）。

## 一、铁律

**装饰层（Decorations）与物品层（Items）只能放「透明底花草树道具」。**

满格不透明硬贴片（一张 20×20 的方形底色图块）铺在地形上就是一块块色斑补丁，
无论撒得多稀疏都难看——它们是"地块"，不是"道具"。

## 四、判定算法（check_decor_tiles.py 同款）

```
op = alpha>128 的像素数（满格=400）
四角 alpha 任一 >128 且 op≥380  → 满格硬贴片（黑）
op≤5                            → 空格（黑）
idx≥1080                        → 超范围（黑）
其余 + 在白名单内               → 安全
```

注意：718/719/754 这类岩石道具**贴着格边画**，个别角像素不透明属正常，
只要整体 op<300、大片透明就是合法道具——不要用"四角必须全透明"误杀。

## 五、布置手法（make_decor v2/v3）

- **成簇高斯散布**，不逐格独立随机：先选簇中心，再按 σ=1.4~2.4 高斯落点，
  同簇 4~13 个，疏密自然。
- **按地貌投放**：林地(HIGHGRASS)→树丛；石/高石→巨岩石堆；沙→褐岩+稀疏草簇；
  泥/土→草簇+孤石；开阔草地→只留零星草簇，保持净空。
- 总密度参考：竞技图 1.5%~2.5%；国家图陆地少，另补 3%~5% 稀疏乡野点缀。
