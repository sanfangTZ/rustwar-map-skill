# 地形兼容矩阵与成片规则（Compatibility & Clustering）

> 本文是**施工前的判断依据**：哪些地形能相邻、哪些组合必然花屏、成片要多大才可见。
> 实测来源：`compat2.py`（两两兼容）+ `probe_cluster.py`（成片命中率）。

## 2. 三色组合：灾难区

**三色 = 某格四邻同时出现 3 种地形** → 必然命中缺失的对角鞍点 → 花屏。

| 三色组合 | 图集命中 | 评价 |
|---|---|---|
| `[0,2,14]` 草/石/高石 | 39/81 | ⚠ 灾难，但比下面好一点点 |
| `[0,2,11]` 草/石/岩浆 | 27/81 | ⚠ 灾难 |
| `[0,2,7]`  草/石/水   | 39/81 | ⚠ 灾难 |
| `[2,7,14]` 石/水/高石 | 27/81 | ⚠ 灾难 |
| `[2,11,14]` 石/岩浆/高石 | 27/81 | ⚠ 灾难 |
| `[0,2,7,14]` 四色 | — | 💀 绝对禁止 |

> **规律**：只要某格四邻出现 **≥3 种**，无论哪三种，图集都大面积缺失。
> → 所以根本约束就是 **"任意格四邻 ≤ 2 种地形"**（见 `terrain_generation.md` §3）。

## 3. 合法邻接图（推荐搭配）

```
        草0 ────── 水7
         │  ╲       │
         │   ╲      │
        石2 ────── (水7 也可与石2邻)
         │
         ├── 岩浆11（仅与石2）
         │
         └── 高石14（仅与草0 / 石2）
```

**推荐分层**：
- 水 7 **只与** 草 0 / 石 2 相邻。
- 岩浆 11 **只与** 石 2 相邻（岩浆田四周包石）。
- 高石 14 **只与** 石 2 相邻（悬崖四周包石）→ 最稳。
- 若高石要邻草 0，则该区域**不能再有石 2**（纯草+高石二色区）。

## 4. 成片规则（★ 决定可见性）

### 4.1 各种并集的图集命中率（实测）

| 地形并集 | 命中 | 说明 |
|---|---|---|
| `{2,14}` | 14/16 | 缺 2 个对角鞍点（全局固有） |
| `{0,14}` | 14/16 | 同上 |
| `{2,11}` | 14/16 | 同上 |
| `{0,2,14}` | **39/81** | ⚠ 三色灾难 |
| `{0,2,11}` | **27/81** | ⚠ 三色灾难 |
| `{2,11,14}` | **27/81** | ⚠ 三色灾难 |
| `{0,2,7}` | **39/81** | ⚠ 三色灾难 |

### 4.2 典型 2×2 组合是否可渲染

| 2×2 组合 | 结果 |
|---|---|
| `(14,14,14,14)` | ✅ OK |
| `(2,14,14,14)` | ✅ OK |
| `(14,14,14,2)` | ✅ OK |
| `(2,2,14,14)` | ✅ OK |
| `(14,14,2,2)` | ✅ OK |
| `(2,14,2,14)` | ✅ OK |
| `(14,2,14,2)` | ✅ OK |
| `(2,2,2,14)` | ✅ OK |
| `(14,2,2,2)` | ✅ OK |
| `(11,11,11,11)` | ✅ OK |
| `(2,11,11,11)` | ✅ OK |
| `(11,11,11,2)` | ✅ OK |
| `(2,2,11,11)` | ✅ OK |
| `(11,11,2,2)` | ✅ OK |
| `(2,11,2,11)` | ✅ OK |
| `(2,2,2,11)` | ✅ OK |
| **`(0,2,14)` 混入** | ❌ BAD |
| **`(0,2,11)` 混入** | ❌ BAD |

### 4.3 成片结论

1. **高石/岩浆必须 ≥ 2×2**，才能穿透顶点采样（孤立 1 格必被抹平）。
2. **2×2 簇周围只能邻石 2**（不得邻草 0、水 7、对方地形）。
3. **两个不同簇（高石簇 vs 岩浆簇）切比雪夫距离 ≥ 4**。
4. **簇外留 2 圈石 2 隔离带**（防迭代修复器破洞导致"贴草"）。

### 4.4 正确画法示意
```
2 2 2 2 2 2 2 2
2 2 2 2 2 2 2 2
2 2 14 14 2 2 2 2      ← 2×2 高石簇，外扩 2 圈石 2
2 2 14 14 2 2 2 2
2 2 2 2 2 2 2 2
2 2 2 2 2 2 2 2
2 2 2 2 2 2 11 11      ← 岩浆簇，与高石簇距离够远
2 2 2 2 2 2 11 11
```

## 5. 快速自检清单（放簇前过一遍）

- [ ] 2×2 本体是纯 `14` 或纯 `11`？
- [ ] 外扩 2 圈（6×6）全是石 `2`？
- [ ] 高石簇与岩浆簇切比雪夫 ≥ 4？
- [ ] 簇离水 ≥ 3 格（`d_water >= 3`）？
- [ ] 簇离出生点足够远？
- [ ] 放完后跑迭代修复器，确认违规 = 0？

## 6. 探测脚本用法

```bash
# 两两兼容
python3 compat2.py
# 成片命中率（各种并集 + 典型 quad）
python3 probe_cluster.py
```

`probe_cluster.py` 输出形如：
```
{2,14} 命中 14/16 (缺2)
{0,2,14} 命中 39/81 (缺42)
(14,14,14,14) -> OK
(2,14,14,14) -> OK
```
