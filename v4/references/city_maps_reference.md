# 城市地图地形参照：东京 / 旧金山（纯文本·全 AI 可用）

> 用户提供 `0.zip`，内含 `东京.tmx`(200×200) 与 `旧金山.tmx`(300×300)。两图均为 RW 标准导出格式（Tiled 1.9、内嵌 tileset `export_ground`、层 Ground/Items/Units），属**城市/写实题材**，与我们的 4V4 是不同风格。此处只提炼"地形可借鉴"的要点，不照搬像素。

## 1. 结构特征（拆解实测）

| 项 | 东京 | 旧金山 |
|---|---|---|
| 尺寸 | 200×200 | 300×300 |
| 地面层 distinct 地形 tile | 36 种 | 66 种 |
| 层 | Ground / Items / Units（无 Triggers 内脚本，纯对局图） | 同左 |
| 资源/物件种类 | Items 层 138 种 GID、Units 层含建筑单位 | Items 226 种、Units 7 种 |

- **题材**：现代城市（道路、街区、港口/海岸），写实风；不是奇幻/战争地貌。
- **地形词汇**：受限但够用（草、土、沙、路、水、各类建筑地块），通过**分层叠加**与**边缘过渡**做出街区感。
- **道路(路)是显式要素**：城市图把"路"作为可通行廊道密集铺设，单位沿路推进顺畅——这正是我们 4V4"路不通"吐槽的反面教材：明确、宽的通道 = 好走。

## 2. 可借鉴到 4V4 的要点

1. **明确的"路"**：在我们地图里用 `土(1)` 铺宽中心带作为陆军通道（见 `passability_bridges.md` 法则 D），模仿城市图"路即通道"的清晰感。
2. **分层地面 + 边缘过渡**：城市图靠地形块平滑拼接出街区；我们已有 `地面层整合.tsx` 四角 autotile，做到海岸/荒漠/草地环状过渡即可（见 `edge_cleanup.md`）。
3. **地形不必贪多**：城市图仅 36~66 种 tile 就做出丰富观感；我们 4V4 用草/土/石/沙/泥/高草/水/浅滩 + 高石屏障已足够，关键是**分布与过渡干净**，而非 tile 数量。
4. **大图更耐玩**：300×300 的旧金山说明大尺度地图容得下多线作战；我们 180×180 的 4V4 已合适，无需盲目放大。

## 3. 与现有参考的关系

- 本图是"城市写实"分支；`pro_map_reference.md`(BC381·地理写实) 与 `map_gallery_heping.md`(和平铁锈·历史写实) 是另两类写实。三者共同构成"写实地图"参照系。
- 4V4 竞技图应取其"清晰通道 + 干净过渡 + 适度地形层次"，而非复制城市建筑细节。
