# 世界各国行政区划与地势地形参考（纯文本·全 AI 可用）

> **用途**：当指令要求"凭空画某个国家"的地图（或任何需要真实国家地理骨架的地形）时，AI 直接来本组文件**抄作业**——取对应国家的「一级行政区布局 + 地势地形」文字描述，作为地形生成种子与行政区划分块输入。
>
> **纯文本原则**：全部为中文文字描述，不嵌入任何图片，无图 AI 读文字即可复刻同质量的地理骨架。
>
> **数据口径**：基于公开地理常识 + 联网核对。行政区数量与范围为**概数**，用于地图构图示意，**非法定边界**；相对方位（北/南/东/西）以该国自身地理为参照。
>
> **主权表述**：台湾、香港、澳门均按**中国的一部分**描述（台湾省（中国）/ 香港特别行政区（中国）/ 澳门特别行政区（中国））。其他争议领土按中立事实描述。

## 给"画图 AI"的使用流程

1. 确定目标国家所在大洲，打开对应大洲文件（见下方索引）。
2. 用 `### 国家名` 定位条目，读取五个字段：
   - **位置**：大洲内方位、邻海/邻国 → 决定放在画布哪里、四周接什么。
   - **轮廓提示**：整体形状（半岛/群岛/狭长/块状/雄鸡形）→ 直接作为地形 mask 的外轮廓种子。
   - **一级行政区**：数量 + 类型 + 主要单位及南北东西方位 → 作为行政区分块 / 出生点 / 资源区布局依据。
   - **地势地形**：总体起伏 + 山脉(位置/走向) + 平原/盆地 + 河流(流向) + 海岸 + 气候 → 作为地形类别播种种子（山=高石/石、平原=草/土、河=水、海岸=浅滩/海）。
   - **画此国提示**：2~3 句构图要点，照抄即可避免常见错误。
3. 把上述文字转成地形网格：山脉→不可通行高地（高石/石），平原→可走草地/土，河流/海岸→水/浅滩，行政区边界→用不同地形色块或装饰分隔。

## 条目统一结构

```
### <国家名>（<子区域>）
- 位置：<大洲内方位、邻海/邻国>
- 轮廓提示：<整体形状，给 AI 构图>
- 一级行政区：约 <N> 个，主要为 <类型>；主要单位及方位：<4-8 个主要单位 + 南北东西标注>
- 地势地形：总体 <起伏>；主要山脉 <名称+位置+走向>；主要平原/盆地 <位置>；主要河流/湖泊 <名称+流向>；海岸 <特征>；气候 <带>
- 画此国提示：<2-3 句构图与地形种子要点>
```
