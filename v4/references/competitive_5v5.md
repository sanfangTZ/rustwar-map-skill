# 5V5 竞技图创作规范（非对称 · 平衡 · 抑空军 · 纯遭遇战）

> 来源：凭空创作 5V5 图三代实战沉淀。v1/v2（破碎峡湾海岸、内陆高原裂谷）采用"中央水道+桥梁"，被用户否决——**"不要水上搭桥这种套路"**；v3（林海雪岭 `gen_5v5_ridge.py`、赤岩裂谷 `gen_5v5_canyon.py`）改为**纯陆地连接**定型。
> 目标：左右各 5 人、**非对称但平衡**、**地形多样**、**空军不能单独定胜负**、**零触发器纯遭遇战**。

---

## 0. ★★ 左右连接只走纯陆地（禁水上搭桥，v3 硬性红线）

"中央挖一条水道再架 3 座桥"是套路化做法，观感廉价且一眼假。左右两半的连接**必须走陆地**，水只允许作为两侧湖泊/海岸**装饰**存在：

| 纯陆地连接范式 | 做法 | 范例 |
|---|---|---|
| **山脊隘口** | 中央连绵山脊(HIGHSTONE 核 + STONE 软边)纵贯南北，脊线上开 3 个草地隘口 | 林海雪岭 |
| **干峡谷走廊** | 中央干峡谷：两侧 HIGHSTONE 崖壁夹一条可行走土质谷底（零水），峡谷只占中段，上/下段是开阔草鞍部 | 赤岩裂谷 |
| **草鞍部** | 山体只占中段，上下两端留开阔草地横越 | 赤岩裂谷南北鞍部 |

要点：
- **峡脊线固定 col=100**（不要随行游走）：游走会让"地图中心到左右出生点的 BFS 距离"不对称，实测平衡差飙到 20.3%。游走感靠崖壁宽度低频"呼吸"+逐格噪声边缘来给。
- 装饰物坐标必须检查左右归属——曾把东侧湖泊写成 (row=168, col=40) 落到左侧，单侧被堵导致平衡差 20%。
- **隘口/鞍部禁完美绿矩形**：只把脊线缺口强制为草，其余保持自然地貌并撒 dirt/高草/石纹理（三者均可通行，不破坏连通），否则像"修剪过的草坪"。
- 通道独立性用"逐条封锁矩形→BFS 复算两侧仍连通"验证（≥3 条）。

## 1. 队伍分配（RW 奇偶敌对规则，硬性）

10 个玩家 `team=0..9`：

- **左侧 5 人 = 偶数队 0,2,4,6,8**（西部一列排开，沿南北分散）
- **右侧 5 人 = 奇数队 1,3,5,7,9**（东部一列排开，沿南北分散）

RW 中**奇偶队互为敌对方**，写反会导致队友互打或无法对敌。出生点不要挤成一团，每侧 5 点沿南北拉开（如 y=22/60/100/140/178）。

## 2. 纯遭遇战（零触发器）

`objectgroup "Triggers"` **只允许**两个对象：

```
map_info      (type=skirmish, winCondition=mainBuilings, fog=los)
camera_start
```

**禁止**任何其它触发器/事件/脚本（区域 buff、历史事件的夺城链一律不要）。交付前用脚本断言：

```python
trigs = [o.get('name') for o in root.find("objectgroup[@name='Triggers']").findall('object')]
assert sorted(trigs) == ['camera_start', 'map_info']
```

## 3. 非对称但平衡（可量化）

**非对称**：左右两侧地貌构成明显不同（如一侧水网峡湾 / 一侧连绵丘陵；一侧湿润高地 / 一侧干旱台地）。不要镜像。

**平衡**（用 BFS 路径距离度量，**不要用直线距离**）：

| 指标 | 合格线 |
|---|---|
| 两侧出生点到地图中心的**平均路径距离**差异 | **< 15%** |
| 两侧每玩家起步矿（res_pool）数量 | 完全相同 |
| 两侧争夺目标（水晶）数量 | 相等（如各 3 个） |
| 两侧后方纵深 / 掩体 | 都有 |

## 4. 空军不能定胜负（4 条落实 + 1 个量化指标）

RW 里空军可飞越一切地形，**地形本身挡不住空军**，所以靠"设计"而非"障碍"来抑制：

### 4.1 中央区开阔度（★核心量化指标，必测）

取中央 80×80 区域，统计**开阔地形**（草/土/沙/浅滩——空军可自由轰炸的面）占比：

- **开阔单类峰值 < 45%** 且**开阔合计 < 55%** → 合格（中央有起伏/掩体，不是一览无余的平原）
- 注意：**高草(森林)/石/高石(崖壁)是掩体不算开阔**——中央是密林反而是好事（藏地面部队、挡视线）。v2 曾误把"高草占比 58%"当超标，实际那是抑空军的加分项；真正的红线是"草/土/沙"这类开阔面。
- 若开阔面 > 55% → **不合格**：中央过于开阔，空军视野与射程独大，会变成"空军占优即定胜负"

**修法**：在中央区（避开通道连接带）用噪声散布 `STONE`（丘岩/视线阻挡）+ `HIGHGRASS`（林丛/隐蔽推进路线）+ `MUD`（洼地），把大片草地打碎。峡谷图实测中央开阔合计仅 38%。

### 4.2 三条以上地面推进通道

左右之间必须 **≥3 条**独立地面通道（北/中/南），避免被单点封锁（尤其防空军封锁唯一通路）。

### 4.3 争夺目标要"地面可占领、且分散"

- 水晶（`crystalResource`, team=-1）总数 4~6，放在**桥头/山口/林间空地**
- **不要**全堆在中央开阔地
- **不要**放在只有空军能到的**孤岛或悬崖顶**（那反而等于送给空军）
- 必须验证：水晶所在格**可通行**（否则地面部队拿不到，等于白送空军）

### 4.4 后方纵深

各玩家基地后方留出缓冲，不贴前线，让空袭偷家需要飞越有代价的距离。

## 5. ★ 坐标写入坑（本次真实踩坑，务必防）

**现象**：水晶本该落在桥头 `(row=36, col=80)`，实际落到裂谷水里 `(row=80, col=36)` → 地面部队拿不到。

**根因**：`get_crystals()` 返回 `(row, col)`，但写入时把两个分量当成 `(col, row)` 用：

```python
# ❌ 错误：把 (row,col) 当成 (col,row) 传给 x,y
for (cc, rr) in crystals:
    add_unit("crystalResource", -1, cc * 20, rr * 20)

# ✅ 正确：x = 列*20, y = 行*20
for (rr, cc) in crystals:
    add_unit("crystalResource", -1, cc * 20, rr * 20)
```

**铁律**：TMX 中 `x` 是**列**(横向)像素，`y` 是**行**(纵向)像素。出生点、水晶、camera 全部统一为 `x=col*20, y=row*20`。

**自检**：生成后解码 tmx，打印每个对象的 `(x//20, y//20)` 与预期 `(col, row)` 比对，并断言水晶所在格可通行。

## 6. 地形多样与自然度

| 指标 | 合格线 |
|---|---|
| 地形种类 | **≥ 8 类** |
| 单一地形最大占比 | **≤ 55%** |

自然度做法（照 `map_gallery_heping.md` 好图法则）：

- 连续噪声高度场 + 阈值映射 → 海陆/山地自然渐变
- 河流**蜿蜒**（正弦 + 噪声扰动），海岸线**弯曲**
- 山脉**连绵**（局部高斯抬升成带），不要孤立圆团
- 陆表**明暗斑块**（草/土/泥/高草斑驳），不要大片纯色块

## 7. 连通性（最严格规则，必测）

不可通行 = `WATER / SEA / OCEAN / HIGHSTONE`。用 BFS 验证 **10 个出生点两两互达**。

桥/通道规则（照 `passability_bridges.md`）：

- 桥核心 **≥6 列纯草地**（推荐固定列窗口 40 列），防止 autotile 拼出双水角过渡贴图被判水
- 桥面在生成**末尾做一次纯度复涂**，防止被后续森林/沼泽/山石覆盖成断点
- 桥面点缀周边起伏时，**必须保护桥面 + 桥头连接带**（否则会把通道堵死）

## 9. ★ 视觉"磕碜"的根因与量化红线（重制版教训）

**症状**：地图看起来像"一块纯色板"、空旷荒凉、山脉像刀切石板。硬指标（多样/平衡/连通）全过，但观感差。

**真因（已从代码确诊）**：
- 高度场/噪声阈值把中间一大段（如 `elev ∈ [-0.12, 0.12]`）全判成 GRASS → **25~28% 地图连成一片纯绿**（实测草地最大连片 10075/11065 格）。
- 装饰只在泥/石上点缀 **0.5%** → 草地空空如也，毫无细节点缀。
- 山脉用 `abs(c-spine) <= half` **硬边直切** → 像两条刀切石板，无有机过渡。
- 中央障碍摆幅太小 → 分割带偏直，缺破碎蜿蜒感。

**★ 量化红线（交付前必测，写脚本解码 Ground 层算）**：
- **草地最大连片（4 邻域连通块）必须 < 10% 地图**（实测好图 5~9%）；超过 15% 即"一块绿板"。
- **装饰密度（Decorations 层非零格）必须 > 1.5%**，目标 3~6%（好图实测 4.75% / 8.74%）。
- 单一地形占比 ≤55% 只是底线；重点是**同类不可连成巨块**（用高频双噪声在草地上撒土/高草/沙斑打碎连片）。
- 山脉必须**软边**：核心 `d <= hw-1.5` 高石、外圈 `d <= hw+0.6` 石，`hw` 加噪声扰动，杜绝硬直角。

**打碎草地的标准写法（已验证）**：
```python
# 对每格陆地用 低频elev(大区) + 中频veg/moist + 高频双噪声(a,b) 软混合
if grid[r][c] == GRASS:
    a = _vn(r, c, 1/9.0); b = _vn(r, c+313, 1/7.0)
    if a > 0.25:  grid[r][c] = DIRT if 左 else SAND   # 土/沙斑
    elif b < -0.25: grid[r][c] = HIGHGRASS             # 草丛斑
# 二次高频土斑网进一步切碎（_vn(r,c,1/7.0) < -0.66 → DIRT）
```

**装饰写法（v2 成簇制，2026 重制教训）**：
- **★ 严禁用带方形底色的贴片当撒点装饰**：826(岩石)/934(枯木)/499(草中树) 等自带沙色/浅灰底色，撒在异色地面上就是一块块"黄白方形补丁"，密密麻麻像芝麻盐——这是观感磕碜的头号根因。
- **只用透明底道具**（`地面层整合.png` 已逐格验证）：雪松 `823/859/860`、灰巨岩 `718/719`、石堆 `754`、黑岩尖柱 `854/855/861`、褐岩造型 `713`、枯根 `935`、草簇 `711/712`。
- **逐格独立随机 → 改成簇投放**：以噪声/随机选簇中心，簇内高斯散布 2~13 个道具（林丛/石滩/灌丛），开阔草地几乎净空（只有零星草簇），疏密自然。参考 `gen_5v5_common.make_decor`（v2）。
- 1006/1007 看着像树其实是蓝白冰晶柱，撒在草地像图腾——选贴片必须先放大合成到底色上目检。
- 密度目标改为 **1.5~3%**（成簇后视觉密度远高于同面积的均匀撒点，宁少勿芝麻）。
