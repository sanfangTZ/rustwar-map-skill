## 1. 花屏根治：`enforce_2type_v2`（收敛型）

**定位**：放在生成管线的最后（texture 与 connect_all 之后、place_mines 之前），是**保证归零的兜底**，不是"尽量修修"。旧法（翻少数类向邻域众数）会在水体边界震荡卡死（实测 45→36），必须淘汰。

**算法**（对每个 >2 类的 2×2 坏块，按成分处置）：
1. **含核心类**（水7/岩浆11/高石14）：保留核心，同框其余类全部翻成"环类"——
   水→草（块内已有草）否则石；岩浆→石；高石→石。核心+环恒为合法二色。
2. **两个核心同框**（如 水+高石）：保留出现较多者，其余核心先翻石，再按单核心处置。
3. **无核心**（纯装饰三色，如 `{泥,石,草}`）：保留"底色 + 块内最多的装饰类"，其余翻回底色。
4. **兜底**：主循环后仍残留 → 坏块整块翻成底色（草地图=草0，雪地图=雪5）。

**★ 收敛的充分条件**：每次翻色**绝不引入坏块原来没有的新类**。违反它的反例已实测：无核心块"整块归一成单类"会给邻块引入新类，坏块数反弹（10→13）。

**★ 底色推断**：全图抽样众数；众数=雪5 则底色取雪，否则取草。底色与一切地形合法，是永远安全的翻色目标。

## 2. 去 AI 味三板斧

### 2.1 blob 第二谐波（破齿轮感）
所有谐波**同频率**时，数学上必然叠加成完美 N 瓣玫瑰花线——这是"齿轮形森林/湖泊"的根源。
修法（new_engine.blob 内加一项）：
```python
h2p = rng.uniform(0, math.tau)
k = sum(amp[i] * math.cos(lobes * a + ph[i]) for i in range(lobes)) / lobes \
    + 0.38 * math.cos((lobes * 2 + 1) * a + h2p)
```

### 2.2 装饰破对称
装饰斑块统一过 `jitter_decor(cv, [(ry,rx,rad,cat),...], rng, amp=6~8)`：对固定镜像坐标加 rng 偏移。矿坑不在此列（官方就是中心对称）。

### 2.3 自然纹理层 texture_pass
- 时机：**所有大特征画完之后**（在 one() 里 builder 返回后调用）。
- 安全区：5×5 邻域**全是底色**，且 5×5 内**无高石/岩浆/水/浅滩/高草**——否则碎斑贴出三岔花屏。
- 调色板：只用土/石/沙/泥（与草/雪皆合法二色），**绝不含高草**。
- 密度：草地图 0.10；雪地图 0.05（雪地图碎斑多了修边尖刺暴涨，实测 462→需减半）。

## 3. 特征放置（scatter）法则

```python
rad = rng.randint(rad_lo, rad_hi)          # ★ 先取本次实际 rad
if any((r-fr)**2 + (c-fc)**2 < (rad + frad + 2)**2 ...):  # ★ 用实际 rad+2，禁用 rad_hi
```
- **用 rad_hi 做排除半径 = 事故**：前几种特征把地图排除饱和，后面的特征一个都放不下（图六"8 片高草林全部饿死、高草=0"）。
- **顺序 = 优先级**：高草林（陆军掩护）→ 水塘（隘口）→ 低丘（制高点）。重要者先放。

## 4. 结构画法

- **水桥必须用石**（`cv.bridge(..., cat=STONE)`）：石↔水、石↔草皆合法二色；草桥视觉上像地峡。桥头两侧水格转 SHOAL 过渡。
- **半岛只伸入、不贯穿**：长 ≤18 格。30 格长半岛把中央湖切成 3 个湖（图八事故）。
- **雪原水系**：水7↔雪5 **非法**。雪图的河/湖必须石环过渡（水↔石 OK、石↔雪 OK）；草图的河/湖直接草岸（水↔草 OK），**不要插石/沙环**（环在凸角被夹窄就出 `{水,石,草}` 三岔）。
- **山体 massif**：石基底半径 > 峰顶外延半径（石必包住高石），多峰随机偏移。
- **岩浆只接石**：岩浆河/池边缘一律 STONE（strip edge / dilate_halo），且与高石簇切比雪夫距离 ≥4。
- **盘山道封边**：紧邻草道的高石降级为石，避免 `{草,石,高石}` 三岔。
- **大结构特征最后落笔**：峡谷壁、断崖等由高石组成的**连续结构**，必须在装饰斑块（高草/泥/沙）和中央台地**之后**绘制。否则装饰斑块会覆盖先落笔的壁，把连续壁"吃掉"，特征弱到不可读（图三首版事故：壁被装饰吃成断断续续的小高石堆）。落笔时对装饰类格（`HIGHGRASS/MUD/SAND`）`continue` 跳过以保装饰完整；草底 strip 可前置重置谷底，壁再后绘保证连续可见。
