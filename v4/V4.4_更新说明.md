# v4.4 更新速览（2026-10）

> 本版核心：**花屏从"生成时小心"升级为"后处理保证归零"，并把去 AI 味/特色化/特征放置的全部实测经验沉淀成方法论。**

## 1. 收敛型花屏根治 `enforce_2type_v2`（本版最大突破）

### 1.1 旧法为什么失败
- 旧 `enforce_2type`（把坏 2×2 里"出现 1 次的少数类"翻向邻域众数）在水体边界**震荡不收敛**：实测图二 45→36 后永久卡死，残留全为 `{水,石,草}`/`{水,沙,石}` 类坏块。
- 根因：同一格在相邻两个坏块里分别被要求翻成不同类，反复横跳。

### 1.2 v2 的分类处置（保二色、灭第三类、绝不引入新类）
| 坏块成分 | 处置 | 结果 |
|---|---|---|
| 含核心类（水7/岩浆11/高石14） | 保留核心，同框其余类全部翻成"环类"：水→草（块内已有草）/石，岩浆→石，高石→石 | 核心+环恒为合法二色 |
| 两个核心同框（如 水+高石） | 保留出现较多者，其余核心先翻石，再按单核心处置 | 消灭非法核心对 |
| 无核心（纯装饰三色，如 `{泥,石,草}`） | 保留"底色+块内最多的装饰类"，其余翻回底色 | 底色与一切合法 |
| 上述之后仍残留 | 兜底：坏块整块翻成底色 | 严格不增，必归零 |

### 1.3 血泪教训（★必读）
- **无核心块"整块归一成单类"是错的**：块变单类看似安全，但该类对邻块可能是新类，邻块反而冒出新坏块（实测图三 10→13 反弹）。正确做法是**保留二色、只消灭第三类**——不引入任何新类，坏块数才单调不增、必然归零。
- 底色（草地图=草0，雪地图=雪5）与所有地形合法，是永远安全的翻色目标。

### 1.4 实测
八图终检：花屏 12/10/20/14/28/0/48/28 → **全部 0**；修边 98.95~99.93%；断路全 0。

## 2. 去 AI 味三板斧（特色化）

1. **blob 第二谐波破"齿轮感"**：旧 `blob` 的所有谐波**同频率**，数学上必然叠加成完美 N 瓣玫瑰花线——高草林/湖泊全是齿轮形。加一项 `0.38*cos((2N+1)a+φ)` 小谐波，轮廓立刻自然。
2. **装饰破对称**：装饰斑块不再用固定镜像坐标，统一过 `jitter_decor`（坐标 + rng.uniform(±6~8)）。矿坑仍按官方"中心对称散布"不动。
3. **自然纹理层**：`texture_pass` 在全部大特征画完之后、只落"5×5 全基面 且 5×5 内无高石/岩浆/水/高草"的安全区，调色板只用土/石/沙/泥（皆与草/雪合法二色），打破"一整片同色"的扁平感。

## 3. 特征放置法则（scatter）

- **排除半径必须用"本次实际 rad + 边距2"**，绝不能用 `rad_hi`——否则前几种特征把地图排除饱和，后面的特征全部放不下（**图六高草林=0 事故**：8 片林一个都没落下，陆军掩护消失、兵种失衡）。
- **放置顺序 = 优先级**：高草林（陆军掩护）→ 水塘（地面隘口）→ 低丘（制高点）。最重要的特征先放，允许后面的被饿死。

## 4. 结构画法修正

- **桥=石跨屏障**：水桥用石（官方风格；草桥视觉上像地峡/浅滩）。石↔水、石↔草皆合法二色，桥头两侧水格转 SHOAL 做过渡。
- **半岛只伸入、不贯穿**：半岛长 ≤18 格；30 格长半岛会把"中央湖"切成 3 个湖（图八事故），母题全毁。
- **雪原水系**：水7↔雪5 **非法**！雪原图的河/湖必须用石环过渡（水↔石 OK、石↔雪 OK）；与草地"水直贴草"画法不同，过渡链必须按兼容矩阵设计。
- **大结构特征最后落笔（图三双峡谷可读性终修）**：峡谷壁、断崖等高石**连续结构**，必须在装饰斑块（高草/泥/沙）和中央台地**之后**绘制。若先画壁、后画装饰，装饰斑块会把连续壁"吃掉"，峡谷退化成断断续续的小高石堆、特征不可读（图三首版事故）。落笔时对装饰类格（`HIGHGRASS/MUD/SAND`）`continue` 跳过以保装饰完整；草底 strip 可前置重置谷底，壁再后绘保证连续可见。
