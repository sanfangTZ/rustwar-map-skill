# 地形生成方法论（Terrain Generation）

> 铁锈战争 tmx 地图的 Ground 层由 **100×100 格 gid** 组成。
> 直接手画 gid 不现实——正确做法是：**先设计 tmx 层面的"地形格矩阵"（每格 1 个地形值），
> 再用渲染器把它转成 gid**。本文讲的就是"地形格矩阵"怎么生成。

---

## 0. 地形值表（本项目约定）

| 值 | 地形 | ASCII | 用途 |
|---|---|---|---|
| 0  | 草 grass      | `.` | 基底 / 出生点 |
| 2  | 石 stone      | `#` | 山体主体 |
| 5  | 雪 snow       |     | 高海拔（可选） |
| 7  | 水 water      | `~` | 河 / 湖 |
| 11 | 岩浆 lava     | `@` | 内部点缀（**须成片**） |
| 12 | 高草 tallGrass |    | 过渡 |
| 13 | 高土 highDirt |     | 过渡 |
| 14 | 高石 highStone | `^` | 悬崖 / 尖峰（**须成片**） |
| 26 | 短草 shortGrass |   | 过渡 |

> 图集里 `gid = tid + 1`，`terrain 顺序 = (左上, 右上, 左下, 右下)`。

---

## 1. 核心铁律

1. **先备份、先侦察**：不动原图，先建工作副本。
2. **分层生成**：水网 → 山体 → 尖峰 → 岩浆 → 隔离修复 → 安全区 → 边缘，**每层单独一步**。
3. **每步可复现**：`random.seed(固定值)`，保证同参同图。
4. **每步后打印统计 + 违规数**，不要等最后才发现。
5. **"四邻 ≤ 2 种地形"是根本约束**（见 §3）。
6. **成片才能可见**（见 §4）——孤立单格的高石/岩浆必然被渲染器抹平。
7. **合规 ≠ 可见**：布局违规 = 0 只是及格线，还要过"渲染可见"这一关。

## 2. 标准生成流程（7 步）

```python
W = H = 100
terr = [[0]*W for _ in range(H)]           # 0=草, 全图基底
random.seed(20260927)                       # 固定种子
```

### 第 1 步 · 水网（暗河 / 河湖）
- 从参照图 `grid_river.json`（或自己生成）取 `>=10` 记为水。
- **侵蚀优化**：做 **2~3 轮**侵蚀 —— 水格四邻中水 < 2 个的，退化为草。
  - 轮数越多，水越"细碎蜿蜒"（像贵州暗河）；轮数少则水成大块湖。
- 记录 `d_water`（每格到最近水的切比雪夫距离），用 **多源 BFS**：

```python
from collections import deque
def bfs_dist(srcs, W, H):
    INF = 10**9
    d = [[INF]*W for _ in range(H)]
    q = deque()
    for (x,y) in srcs:
        d[y][x] = 0; q.append((x,y))
    while q:
        x,y = q.popleft()
        for dx,dy in ((1,0),(-1,0),(0,1),(0,-1)):
            xx,yy = x+dx, y+dy
            if 0<=xx<W and 0<=yy<H and d[yy][xx] > d[y][x]+1:
                d[yy][xx] = d[y][x]+1; q.append((xx,yy))
    return d
```

### 第 2 步 · 山体峰丛（"贵州峰丛"的灵魂）
- 撒 **N 个峰心**：`randint(5, W-6)`，避开出生点、`d_water >= 2`、峰心间距 `< 5` 就跳过。
- 每个峰心画一个 **blob（带噪声的圆）**：

```python
def blob(cx, cy, r0, jitter):
    for ang in [i*0.1 for i in range(63)]:
        r = r0 + jitter*math.sin(3*ang + cx*0.7 + cy*0.3) + 0.6*math.sin(5*ang)
        for rr in range(int(r)+1):
            xx = int(round(cx + rr*math.cos(ang)))
            yy = int(round(cy + rr*math.sin(ang)))
            if 0<=xx<W and 0<=yy<H and terr[yy][xx]==0 and d_water[yy][xx]>=3:
                terr[yy][xx] = 2
```
- 参数参考：峰心 **55** 个、`r0=2.4~5.0`、`jitter=0.6~1.8` → 成片连绵的"峰丛"。
- **落点 `d_water >= 3`**：给水留 3 格隔离，避免 `[0,2,7]` 三色（见 §3 灾难）。

### 第 3 步 · 连脉（把孤立山头连成山脉）
- 峰心两两之间距离 `<= 32` 时，画一条摆动带把它们连起来：

```python
hw = 1.6 + 0.7*math.sin(0.4*t)      # 半宽随 t 摆动
off = 2.4*math.sin(0.5*t)           # 横向摆动
```
- 落点同样 `d_water >= 3`。
- → 山体从"孤立群岛"变成"连绵山脉"。

### 第 4 步 · 尖峰 / 悬崖（高石 14）★ 必须成片
- **不能单格放**！必须 **2×2 方块簇**（见 §4）。
- 候选条件：**2×2 本体 + 外扩 2 圈（共 6×6）全是石 2**。
- 簇间距切比雪夫 `>= 4`。

```python
def is_pure_stone_block(x, y, half):
    for dy in range(-half, 2+half):
        for dx in range(-half, 2+half):
            xx, yy = x+dx, y+dy
            if not (0<=xx<W and 0<=yy<H) or terr[yy][xx] != 2:
                return False
    return True
```
- 放 N 颗（本项目 15 颗 ×4 格 = 60 格）。

### 第 5 步 · 岩浆（11）★ 必须成片
- 同样 **2×2 方块簇**，候选同第 4 步。
- **与高石簇切比雪夫距离 >= 4**（防止 `[2,11,14]` 三色）。
- 放 M 颗（本项目 3 颗 ×4 格 = 12 格）。

### 第 6 步 · 通用迭代修复器（兜底）★ 极其重要
即使前面都守规矩，也可能因为层间叠加出现零星"四邻 > 2 种"的格。用一个**迭代修复器**扫平：

```python
for _round in range(60):
    viol = [(x,y) for y in range(H) for x in range(W)
            if len({terr[yy][xx] for xx,yy in neighbors(x,y)}) > 2]
    if not viol: break
    changed = 0
    for (x,y) in viol:
        cnt = Counter(terr[yy][xx] for xx,yy in neighbors(x,y))
        best = None
        for cand in list(cnt.keys()) + [terr[y][x]]:
            if len(set(cnt) | {cand}) <= 2 and (best is None or cnt.get(cand,0) > best[0]):
                best = (cnt.get(cand,0), cand)
        if best and best[1] != terr[y][x]:
            terr[y][x] = best[1]; changed += 1
    if changed == 0:                # 兜底：改成邻居众数
        for (x,y) in viol:
            terr[y][x] = Counter(terr[yy][xx] for xx,yy in neighbors(x,y)).most_common(1)[0][0]
```

> **注意**：修复器会改最外圈石 2 → 所以高石/岩浆簇必须留 **2 圈**隔离带，否则修完变"贴草"。

### 第 7 步 · 出生点安全区 + 边缘
- 4 个出生点 `(3,3)/(3,96)/(96,96)/(96,3)`：
  - 中心 **3×3 强制纯草**（gid 38）；
  - 半径 `SAFE_R=3.4` 内柔化归草，但 **不动 `11/14`**。
- 边缘 2 格归草（防图集越界）。

## 3. 根本约束：四邻 ≤ 2 种地形

**为什么？** 渲染时每个 **tile 的四角** 只取一种地形组合，只有"任意格四邻 ≤ 2 种地形"才能保证每个 tile 四角最多 2 种。一旦某格四邻出现 **3 种**，就会命中图集里**缺失的对角鞍点**，渲染花屏。

**合法的邻接集合**（实测）：
```
草0 ↔ 水7      草0 ↔ 石2      石2 ↔ 水7
石2 ↔ 岩浆11   草0 ↔ 高石14   石2 ↔ 高石14
```

**灾难性三色组合**（图集覆盖率极低，禁止）：
| 组合 | 图集命中 |
|---|---|
| `[0,2,14]` 草石高石 | 39/81 ⚠ |
| `[0,2,11]` 草石岩浆 | 27/81 ⚠ |
| `[0,2,7]`  草石水   | 39/81 ⚠ |
| `[2,7,14]` 石水高石 | 27/81 ⚠ |
| `[2,11,14]` 石岩浆高石 | 27/81 ⚠ |

> 凡含 ≥3 种地形的 quad 并集，都大面积缺失 → **必须靠隔离带杜绝**。
> 高石 14 **尤其娇气**：只能邻草 0 / 石 2。

## 4. ★ 采样分辨率陷阱：布局合法 ≠ 渲染可见

### 渲染器怎么工作
每格 tile 的 4 个角，各由"**该角周围 2×2 个地形格**"做**多数投票**决定。
平票时取**较小的地形值**。

### 陷阱
**孤立 1 格高石 14**，被 3 个石 2 包围：
```
2 2
2 14   ← 只占 1/4，永远投不过石2
```
→ 四个角全被判成石 2 → **渲染后完全看不见**！
（本项目实测：60 格单格高石 + 10 格单格岩浆，`gids.json` 里**一个相关 gid 都没有**。）
即使在 4 格全石 2 中的单格高石、或"石石石高"的角，高石也只有 1/4 票。

### 破解：成片 ≥ 2×2
`2×2 高石簇`能让**簇内四角**各拿到 **≥ 2/4 高石票** → 稳定渲染为**悬崖块**。
实测可用组合（全部命中图集）：

| 2×2 组合 | 是否可渲染 |
|---|---|
| `(14,14,14,14)` | ✅ |
| `(2,14,14,14)` `(14,14,14,2)` | ✅ |
| `(2,2,14,14)` `(14,14,2,2)` | ✅ |
| `(2,14,2,14)` `(14,2,14,2)` | ✅ |
| `(2,2,2,14)` `(2,2,2,11)` | ✅ |
| `(11,11,11,11)` 及岩浆同型 | ✅ |

### 2×2 簇的正确画法
```
外扩 2 圈 = 石2 隔离带（防修复器破洞 + 防三色）
  2 2 2 2 2 2
  2 2 2 2 2 2
  2 2 14 14 2 2
  2 2 14 14 2 2
  2 2 2 2 2 2
  2 2 2 2 2 2
```
